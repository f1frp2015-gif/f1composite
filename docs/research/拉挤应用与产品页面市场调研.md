## 1. 决策与证据口径

首轮完成 **8 个应用专业页和 6 个产品专业页**；用户进一步授权深挖、更新导航和部署后，v1.1 扩展为累计 **13 个应用专业页和 11 个产品专业页**。应用页回答“用在何处、怎样提出正确的工程要求、如何连接安装和维护”；产品页回答“具体买什么、图纸怎样定义、采用什么公差和验收记录”。同一主题的两个页面不应重复一份营销长文。

优先级基于三个判断：当前网站缺少独立专业页；指定同行有直接应用证据；能够从标准组织、监管部门或设备制造商取得足够信息解释其适用边界。这里没有进行市场规模估算、搜索量测量或销售额预测，页面优先级不能表述为已经验证的市场排名。

证据分三层使用：

| 层次 | 能支持什么 | 不能支持什么 |
| --- | --- | --- |
| 同行官网、设备 OEM 官网 | 某种构件确实用于该场景；有哪些接口、制造路线和选型问题 | F1 具有同行的配方、设备、批准、工程责任或已交付案例 |
| 标准制定机构、监管部门的公开范围和版本页 | 标准名称、版本、适用对象、法规管辖以及需要进一步查阅的条款体系 | 未读全文时的细节阈值；任何供应商已符合标准；标准在所有国家自动成为法律 |
| 本次原创工程建议 | 将场景转为图纸、工况、接口、试样、验收和责任清单 | 未经设计计算的承载能力、施工图、寿命保证或项目批准 |

页面中的示例采购情境均必须注明为 illustrative workflow，不得伪装成 F1 真实订单。

## 6. 版本与适用范围的关键纠正

### 6.1 水处理标准不能忽略成型方法

AWWA 官方清单列出 **F101-25** 和 **F102-25**。前者针对接触成型的槽和集水槽，后者针对匹配模具成型的堰板、浮渣挡板及相关零件。采购规范引用它们时，若采用拉挤方案，须由项目规范方处理制造路线差异及认可条件，不能直接复用同行的“compliant”措辞。[官方范围](https://www.awwa.org/resource/wastewater/)、[已发布清单](https://www.awwa.org/standards/standards-list/)

ASTM D3917 是标准型材尺寸公差的依据，不提供刮泥机额定载荷。ASTM D7290 提供土木复合材料统计特征值方法，不是整机资格。ASTM D543 的化学评估需要代表实际工况，不能从短时浸泡推出无限使用寿命。[D3917](https://store.astm.org/d3917-23.html)、[D7290](https://store.astm.org/d7290-06r22.html)、[D543](https://store.astm.org/d0543-21.html)

### 6.2 CFRP 加固区分设计规范、指南和 kit 评估路线

采用 **EAD 160086-01-0301**；EOTA 清单将较早的 `160086-00-0301` 标为被替代。评估对象是外贴和近表面嵌贴 CFRP 板条加固 kit。EAD 是评估文件，不等于 F1 已有 ETA，也不等于任意碳板、胶和基层可自由拼成同等系统。[EOTA 清单](https://www.eota.eu/eads)、[新版 EAD](https://www.eota.eu/download?file=/2018/18-16-0095/for+ojeu/ead+160086-01-0301_ojeu+2025.pdf)

EAD §1.1–1.2 还限定为单向碳/环氧板条与环氧结构粘结剂组成的套件。板条需在工厂形成要求的宽度和厚度，现场切宽不在该范围内；切长度是另一项安装操作，须遵循所选套件要求。其预期用途不包含抗震加固或预防用途。这些边界已经同步到应用和产品页的标准说明。[EAD 原文](https://www.eota.eu/download?file=/2018/18-16-0095/for+ojeu/ead+160086-01-0301_ojeu+2025.pdf)

**ACI CODE-440.13-24** 是项目采用时的设计规范路线，不因发布而自动在全美生效。官方预览 §1.1–1.2 针对既有混凝土和其第 4 章允许的单向外贴/近表面嵌贴体系，排除砌体；Seismic Design Categories B–F 中抗侧力体系构件的抗震加固不在其范围内。设计方须确认当地和项目采用文件。[ACI 规范目录](https://www.concrete.org/store/productdetail?ItemID=44013U24&Language=English&Units=US_Units)、[官方公开预览](https://www.concrete.org/Portals/0/Files/PDF/Previews/440.13-24_preview.pdf)

**ACI PRC-440.2-23** 继续作为工程指南使用，不能写成已被上述 code 全面取代或失效。指南、设计规范和 EAD kit 评估的作用不同，三者均不能单独证明 F1 产品已获批准。[ACI 指南目录](https://www.concrete.org/store/productdetail?ItemID=440223&Language=English&Units=US_AND_METRIC)

### 6.3 IEC 61373:2026 不覆盖所有轨道型材

IEC 官网确认 **61373:2026** 为第 3 版，2026 年发布。它用于规定范围内的铁路车辆设备冲击和振动测试；新版明确排除牵引电机以及未装电气、电子或气动装置的子结构等对象。裸支撑型材或纯机械次级结构不能因为装在列车内就自动适用。OEM 应确定设备对象、安装状态、试验和分析路线。[IEC 官方说明](https://webstore.iec.ch/en/publication/68999)

### 6.4 F711 新版、旧版报告和法规引用要分别记录

ASTM 当前目录是 **F711-26**；既有报告可能引用 `F711-17(2022)` 等旧版。美国 OSHA 1910.269(j) 现行条文注释仍引用 **F711-02 (2007)**。三者需要在评估记录中分别列明，不能将当前目录版本自动替换进法律条文。F711 的棒/泡沫填充管范围不覆盖完整工具的所有附件；IEC 60855-1 所描述的系统电压范围也不能转换成 F1 未经资格确认产品的工作电压。[ASTM](https://store.astm.org/f0711-26.html)、[OSHA 现行条文](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.269)、[IEC](https://webstore.iec.ch/en/publication/24654)

旧 OSHA 解释信可能引用更早的 F711 版本，不能用解释信覆盖目前条文。本轮以当前监管页面为准；不在网站写带电作业操作教程。

### 6.5 第三轨是固定设施，车内饰是车载材料

固定第三轨盖板首先需要与轨道电气防护、接地和回流系统协调。EN 45545-2 的范围是车辆材料及产品；除非项目另行引用所需测试，它不是固定第三轨的通用合格证。相反，内装型材需要按真实部件确定 EN 45545 要求集和危险等级，且该结果不能证明整车碰撞、结构耐火或线路电气安全。[EN 50122-1](https://landingpage.bsigroup.com/LandingPage/Undated?UPI=000000000030171497)、[EN 45545-2](https://www.nen.nl/en/nen-en-45545-2-2020-a1-2023-en-316338)

## 7. 为什么采用 component qualification，而非库存销售承诺

本轮取得的是行业场景与标准范围证据，并未取得这 14 页所涉及每一种专用组件的完整 F1 模具表、行业批准、批量交付记录和产品级测试报告。已有通用型材或碳纤维制造介绍能支持初步可行性讨论，不能自动证明第三轨、带电工具、加固 kit 或精密旋转部件的终端资格。

因此页面公开范围采用“可评估图纸与组件资格确认询盘”：先取得设计输入，确认供货与分工，再确定打样、测试、变更和量产放行。不得因为页面位于 `/products/` 就生成价格、库存、认证标章、额定电压、轨道危险等级或整机可用声明。

| 升级到具体供货声明前需要什么 | 对应确认内容 |
| --- | --- |
| 受控图纸及接口数据 | 截面、长度、加工、配件、安装环境和责任方 |
| 材料与工艺记录 | 实际配方/构造、增强方向、表面、加工和批次身份 |
| 适用试验与报告 | 试样是否代表拟供组件，报告的范围、版本和认可条件 |
| 首件及总成确认 | 试装与性能确认分别记录，明确组件和设备责任 |
| 可追溯生产及变更规则 | 量产检查、材料替换、返修、配件变化及客户放行 |
| 合同范围 | 设计、原料、型材、加工、测试、安装及整机验收分别界定 |

公开页面重点是帮助采购方提出正确需求，而不是展示内部技术实现。F1 真实证据具备后，再更新对应页面的具体能力，不反向用页面内容充当证据。
