## 〇、先处理：代码仓库是公开的

核对时发现，GitHub 仓库 `f1frp2015-gif/f1composite` 是 **public**。任何人不登录就能：
- 下载整站源码、设计系统、全部文案和数据；
- 看到价格引擎 `lib/pricing/engine.ts` 里的成本、管理费、利润和出口加价系数；
- 拿到所有图片原件。

这比任何网页上的防护都关键：价格接口的限流和这次的照片水印，都挡不住直接从 GitHub 拿源文件。

**建议业主立即改为私有。** 操作路径：GitHub 仓库 → Settings → General → Danger Zone → Change repository visibility → Private。

改私有后：
- Vercel 通过已安装的 GitHub App 访问仓库，部署照常。改完后请看一次 Vercel 是否正常出新部署。
- GitHub Actions 在私有仓库按账户套餐计分钟数（免费账户每月 2,000 分钟）。可以在 Settings → Billing 看用量。
- 已经被别人克隆或下载的副本收不回来。可以在仓库 Insights → Traffic 查看最近 14 天的克隆次数。价格系数自 2026 年 4 月起一直公开，必要时评估是否调整。

快速扫描了最近 475 个提交，没有发现提交进仓库的 API 密钥或数据库连接串。仓库是浅克隆，更早的历史没有覆盖到。

**水印位置**
- 网站各处都按不同比例居中裁切照片。`lib/photoMark.ts` 为每张图挑选右下角的边距，保证在首页大图、插图、卡片、手机条幅等所有比例下，水印要么完整显示，要么整个被裁掉，不会只露半截。
- 实际效果：
  - 首页大图、案例页、板材页上水印被裁掉，页面观感不变；
  - 关于我们页的厂房图在右下角完整显示一个小水印；
  - 别人下载到的文件，无论哪个尺寸，都带水印。
- 测试 `scripts/owned-photos.test.mjs` 检查：
  - 水印和元数据都在；
  - 没有半截水印；
  - 旧文件已删并已跳转；
  - 自有照片没有被标成图库图或供应商图。

**局限**
- Next 的图片优化会去掉缩略图里的元数据，所以随图片传播的主要是可见水印。元数据保留在 `/images/f1-photos/` 下的原图里。

- 水印可以被裁掉或修掉。它的作用是让盗用显而易见，并在投诉时作为证据。

## 二、商标申请方案（待业主和商标代理执行）

> 官费和判例来自各官方网站和法院文件，截至 2026 年 10 月。研究时无法直接打开官网页面，数字取自搜索引擎对官方页面的摘录。提交前请代理逐项复核，“待核实”的不要直接使用。

### 1. 先由业主决定的四件事

1. **申请人**：Chongqing F1 Composites Co., Ltd.（出口公司），还是风渡集团母公司。商标归属决定以后由谁投诉和维权，经销商授权也从这里出。
2. **中国基础注册**：马德里国际注册必须以中国申请或注册为基础。公司在中国是否已有 “F1 COMPOSITE” 或图形标的申请或注册？
3. **标识写法**：
   - Logo 上写的是 “F1 COMPOSITES”（复数），网站品牌是 “F1 Composite”。注册的标志要和实际使用一致，请先统一。
   - 产品线名 F1-STRUX、F1-GRID、F1-THERM、F1-FORM 在待办里还“待业主确认”，确认后再申请。
4. **预算和市场优先级**：见下文。

### 2. 申请哪些标

| 优先级 | 标志 | 理由与风险 |
|---|---|---|
| 1 | “F1 COMPOSITE” 文字和绿色图形 logo（组合标） | 主品牌，投诉和平台备案都用它。“COMPOSITE”是描述性词，美国会要求声明不单独主张 |
| 2 | “F1-STRUX” | 结构型材线，STRUX 是自造词，显著性较好。需要检索在先的 STRUX 类商标 |
| 3 | F1-GRID、F1-THERM、F1-FORM | GRID（格栅）、THERM（隔热）、FORM（成型）对各自产品偏描述性，可注册性主要靠 “F1”。可以放到第二批 |
| 不建议 | 单独的 “FENGDU” | 丰都是重庆的县名，中国《商标法》第十条禁止县级以上行政区划地名作商标，作为马德里基础标风险高。如果“风渡”与“丰都”是不同的字，请代理另行评估 |

### 3. 类别（尼斯分类第 13 版，2026-01-01 起施行）

| 类别 | 覆盖的产品 | 建议 |
|---|---|---|
| **19** | 非金属建筑材料：拉挤型材（梁、槽、角、管）、玻璃钢格栅、非金属门窗及窗框、扶手、玻璃纤维筋、非金属光伏支架 | **必选**，核心类 |
| **17** | 供进一步加工用的塑料半成品（玻璃钢板、棒） | 建议 |
| 20 | 塑料梯子 | 有梯子品牌销售时再加 |
| 6 | 金属紧固件、卡扣 | 只在用品牌卖金属件时 |
| 40 | 为他人定制加工（拉挤代工） | 做 OEM 业务时建议 |

### 5. 与一级方程式（Formula One Licensing B.V.）的冲突风险

已查到的判例：
- **欧盟**：
  - 2012 年欧盟法院 C-196/11 P（F1-LIVE 案）认定，异议程序中在先的 “F1” 成员国文字商标须被推定具有一定显著性。
  - 2015 年欧盟普通法院 T-55/13（F1H2O 案）认定，F1 的声誉只及于其图形标，不及于文字商标，F1 方败诉。
  - 2023 年起，F1 在欧盟的部分商标因不使用被部分撤销。
- **英国**：结果有输有赢。2014 年 TEAM F1 案在相同商品（第 9 类）上 F1 方胜诉；2020 年另一起异议 F1 方败诉。
- **新加坡**：2015 年 F1H2O 案 F1 方败诉。
- **美国**：未查到 TTAB 关于 “F1” 的裁决。

判断：
- 第 17、19 类的建材与赛车相距很远，F1 的声誉主要附着在图形标上，构成混淆的风险**较低**。
- 但 F1 方异议积极，**被提异议的可能性存在**，即使大概率胜诉也会拖延时间、增加费用。

降低风险的做法：
- 不使用赛车元素、红黑速度线条，或任何与 F1 图形标相似的设计。现有绿色渐变 logo 与之差别明显。
- 申请前由代理做一次 “F1” 在第 17、19 类的在先商标检索，包括 Formula One 名下的注册。
- 预算里留出应对一次异议的费用。

### 7. 注册后能做什么

| 工具 | 需要什么 |
|---|---|
| 亚马逊品牌备案 | 需要已注册商标，或特定局的在审申请。通过亚马逊 IP Accelerator 的律所申请可提前备案。卖家论坛称直接向 USPTO 提交的在审申请不被接受 |
| 阿里巴巴知识产权保护平台 | 需要商标证书。是否接受在审申请待核实 |
| Google Ads | 可以对广告文字中使用你商标的广告投诉，但只在你能证明拥有商标权的国家有效；关键词本身不受限制 |
| 域名争议（UDRP） | 仅有在审申请不足以证明商标权，最好等注册后再处理仿冒域名 |
| 海关备案 | 美国海关、欧盟海关都可以备案注册商标，拦截仿冒货物。这一条是常规做法，未单独查官方条件 |

**网站上的标注**：
- 注册前，可以在美、英、澳、加使用 “™”。
- “®” 只能在该国注册后使用。英国和澳大利亚等地，把未注册商标标成注册商标是违法的。
