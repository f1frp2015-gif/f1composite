# 报告核验页与价格接口防护（2026-10-02）

目标：网站继续对搜索引擎和 AI 完全公开，同时提高同行批量抓取价格、冒用检测报告的成本。

## 一、价格接口与目录接口

| 接口 | 改动 | 正常用户 | 批量抓取 |
|---|---|---|---|
| `POST /api/profile-price` | 同源校验（`lib/browserRequest.ts`）+ 每个 IP 5 分钟 90 次、每天 400 次 | 浏览器在估算器页面自动带 `Sec-Fetch-Site: same-origin` 和 `Origin`，不受影响。估算器每次改动 400 ms 后请求一次，一个人试几十个尺寸也用不到上限 | 直接用脚本调用返回 403；同一 IP 超额返回 429 |
| `GET /api/catalog` | 每个 IP 10 分钟 30 次 | 规格书生成器每次打开页面只取一次 | 反复整份抓取会被限 |

为什么要防：价格接口返回的区间是成本模型算出来的，采样足够多就能反推出系数。同源校验挡住直接调用的脚本，限流限制单个 IP 的采样量。

局限：
- 伪造请求头的脚本仍可通过同源校验。
- 限流计数存在单个服务器实例的内存里，多 IP 轮换可以绕过。
- 要更强的防护，可以把计数换成 Upstash 或 Vercel KV（`lib/rateLimit.ts` 已留接口），或在 Vercel 后台开启机器人防护或 BotID。
- 这次没有加 BotID：从这里无法在 Vercel 上实测，判错会让估算器对真实用户失效。开启后要先在预览环境确认估算器能正常出价。

GEO 作用：有人在搜索引擎或 AI 里查报告编号时，找到的是 F1 的核验页，页上写明持证方和核验路径。冒用者无法改变这一点。

## 三、关于“PDF 加水印”的取舍

实验室原件一律不加水印、不改动，理由如下：

| 文件 | 原因 |
|---|---|
| Intertek 001/002 | 带数字签名；声明第 3 条“涂改无效” |
| SGS SHIN…CM01/CM02、SGS GZMR 中文原件 | 带数字签名（GZMR 中文原件还有加密）；SGS 页脚写明未经书面批准不得非全文复制，任何改动外观属违法 |
| 无锡 2025DACS20319 中文原件 | 带数字签名；注意事项第 4 条“报告涂改无效” |
| TÜV CN24KZ3A 002/003 | 版权归 TÜV；须完整使用 |
| PHI 证书 | 机构签发的证书 |

改动任何一个字节都会让签名核验失败，反而让买家无法确认真伪。

替代做法：
- **核验页**：持证方声明和 SHA-256 写在核验页上。
- **F1 自己的英文注释副本**（SGS GZMR 英文版、无锡 2025DACS20319 英文版）：在右侧注释栏底部每页加注一行，写明持证方、仅覆盖持证方送检样品、核验网址。实验室原页面不动。脚本为 `scripts/stamp-annotated-reports.py`，重复运行会跳过已加注的页面。
- **测试锁定**：`scripts/evidence-protection.test.mjs` 锁定 9 个实验室原件的 SHA-256，任何改动都会让测试失败；机构换发新版时替换文件并更新哈希。

## 四、核对时发现、需要业主处理的事项

1. **TÜV 报告缺签名**：CN24KZ3A 002/003 写明“仅数字签名”，但站上的 PDF 没有内嵌签名，核验页已如实说明。请向 TÜV 索取带签名的原版替换。
2. **使用许可**：
   - TÜV 附加条款第 4 条：客户为广告目的公开或复制须事先取得 TÜV 书面同意。
   - Intertek 声明第 5 条：销售或广告中使用 Intertek 名称须事先书面批准。

   网站公开这些报告并在标题里使用机构名称，建议取得书面许可。这与待办里“摘录数值”一项是两件事。
3. **集团关系**：核验页写明 Fengdu New Material (Yancheng) Co., Ltd. 和 Chongqing Fengdu New Material Co., Ltd. 属于风渡集团，请确认。
4. **PHI 证书到期**：2491wi03 有效期到 2026-12-31。
5. **EPD 与三星证书**：英文摘要的持证方写法与其他报告不一致（已在待办中）。这两份不是机构原件，所以这次没有做核验页。拿到中文原证书后可以补上。
