## 四、需要业主决定或提供依据的事项

1. **标准型材目录的单重与密度 1.9 g/cm³ 不一致。** 按名义截面反推，工字钢、槽钢、角钢和方圆管的密度约为 1.4–1.6，棒材和扁条约 1.82。例如 I 200×100×10 截面积 3,800 mm²，按 1.9 应为 7.2 kg/m，目录写 5.8 kg/m。这些单重进入了尺寸表、跨度表、价格估算和 JSON-LD。需要确认是目录单重有误，还是名义截面与实际截面（圆角、壁厚）有差别。
2. **矿用 / 油田管目录 PDF 需要出新版。**
   - 管材引用的 MT 558.2 是 PVC 管那一部分，FRP 矿用管对应 MT/T 558.3-2005。站内描述已改，PDF 未改。
   - PDF 写有“≥50 年设计寿命”“免维护”“Qualified to API 15LR / ISO 14692”，与站规冲突。
   - Series 02 表面电阻 ≤3×10⁸ Ω，不满足 MT/T 558.3 对瓦斯抽采管 <1×10⁶ Ω 的要求。
3. **3-Star 和 EPD 的英文摘要 PDF** 把持证方写成“F1 Composite Co., Ltd.”及其盐城工厂，与法定名称和主体关系不符。需按 CABR 原件核对持证方后重新出摘要。
4. **设计手册 Rev. B 的 PDF 与网站已不同步。** 涉及高温系数、环境说明、欧盟和加拿大规范行、防火说明，以及“Eurocode by 2028”的表述。需要用 `npm run build:manual` 出 Rev. C，同时更新证据哈希。风电层合板数据表 PDF 仍写 DNVGL-ST-0376 2015 版，且有重复的 γMb。
5. **案例中无法核实的数字**：

   - 英国码头：500 m、4 周完工。
